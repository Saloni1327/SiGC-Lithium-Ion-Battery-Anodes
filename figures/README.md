# Figures

This folder contains selected figures from the SiGC composite anode study.

## Processing and characterization

- `process_flowchart.jpeg` — Overview of the SiGC composite preparation and electrode fabrication process.
- `xrd_analysis.png` — X-ray diffraction analysis of the SiGC composite materials.
- `eds_analysis.png` — Energy-dispersive X-ray spectroscopy analysis of the composite.
- `elemental_mapping.png` — Elemental mapping showing the spatial distribution of the detected elements.
- `tem_microstructure.png` — Transmission electron microscopy image showing the composite microstructure.

## Electrochemical characterization

- `cyclic_voltammetry.png` — Cyclic voltammetry response of the fabricated electrode.
- `initial_charge_discharge.png` — Initial charge–discharge behavior of the electrode.
- `final_charge_discharge.png` — Final charge–discharge behavior reported in the study.

## Notes

The figures are included for portfolio and research documentation purposes. Raw experimental data and complete manuscript files are not included in this repository.
