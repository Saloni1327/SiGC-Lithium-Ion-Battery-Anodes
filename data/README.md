# Data

This folder documents the experimental data associated with the SiGC composite anode study.

The current repository does not include the raw electrochemical measurement files. Reported values and observations are documented based on the research manuscript.

## Experimental Groups

Two SiGC batches were investigated:

- **Unsieved Si:** Silicon powder used without sieving.
- **Sieved Si:** Silicon powder passed through a 100 µm mesh.

Electrochemical characterization included:

- Open-circuit voltage (OCV)
- Cyclic voltammetry (CV)
- Galvanostatic charge-discharge testing
- Cycling stability
- Electrochemical impedance spectroscopy

Reported capacity and retention values are summarized in the `results/` directory.
